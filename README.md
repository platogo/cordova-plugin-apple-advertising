# cordova-plugin-apple-advertising

A Cordova iOS plugin that provides access to Apple's advertising framework, allowing apps to retrieve the IDFA (Identifier for Advertisers) and check the tracking authorization status. This plugin requires `cordova-ios` 6.0.0 or later and targets iOS 11.0+; on these versions the Swift standard libraries are handled by the Xcode / `cordova-ios` toolchain, while projects targeting older iOS versions may need additional Swift stdlib embedding configuration.
